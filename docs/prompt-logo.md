# Prompty do logo – dr Marta Kryczka

Kolory: taupe `#5F452F`, piaskowy beż `#E9DDD0`, złamana biel `#FAF7F4`. Zakaz: zęby, strzykawki, krzyże, stetoskopy. Każdy prompt wklej w całości do wybranego narzędzia (Midjourney, Ideogram, DALL·E, Canva AI).

## 1. Sam symbol (najważniejszy – zaczynaj od tego)

```
Minimalist abstract logo symbol for a personal brand of a female doctor in aesthetic
medicine and orthodontics. A single continuous thin line forming a soft smile curve
that also reads as the profile of a face, expressing harmony and proportion. Flat vector,
monoline, deep taupe-brown (#5F452F) on off-white (#FAF7F4), centered, lots of empty space.
No text, no letters, no gradients, no 3D, no teeth, no syringe, no cross.
--no text, letters, tooth, syringe, cross, gradient, 3D, photo
```

## 2. Monogram „MK”

```
Elegant monogram logo with the letters "M" and "K" intertwined, refined high-contrast
serif style, thin hairline strokes, luxury medical-aesthetic feel. Deep taupe-brown
(#5F452F) on soft sand beige (#E9DDD0), perfectly centered, flat vector, suitable for a
circular social media avatar. No other text, no gradients, no 3D, no decorative clutter.
```

## 3. Logo poziome z napisem

```
Horizontal logo lockup: a small abstract smile-curve face-profile symbol on the left and
the text "dr Marta Kryczka" on the right, in a refined high-contrast serif typeface
(Playfair Display style), below it a small spaced uppercase line "MEDYCYNA ESTETYCZNA · ORTODONCJA"
in a light sans-serif. Deep taupe-brown (#5F452F) on off-white (#FAF7F4), flat vector,
generous spacing, premium, calm, trustworthy. No gradients, no 3D, no photorealism.
```

## 4. Wariant sam napis (wordmark)

```
Wordmark logo, only the text "dr Marta Kryczka" in an elegant high-contrast serif font,
slightly increased letter spacing, the "dr" in lowercase and smaller, a thin hairline
underline accent. Deep taupe-brown (#5F452F) on off-white (#FAF7F4), flat vector,
minimalist, premium. Correct spelling exactly: dr Marta Kryczka. No other elements.
```

## 5. Wariant ciemny (negatyw)

```
Same minimalist logo for "dr Marta Kryczka" in negative version: sand beige (#E9DDD0)
lines and text on deep taupe-brown (#5F452F) background, flat vector, centered, elegant
serif wordmark with a small abstract smile-profile symbol. No gradients, no 3D.
```

## 6. Wariant ciepły, bardziej artystyczny

```
Refined hand-drawn single-line logo mark of a woman's face profile blending into a gentle
smile, delicate and feminine, with the wordmark "dr Marta Kryczka" in a light serif.
Muted warm palette of taupe, sand and cream. Flat vector, airy, modern, premium
aesthetic-medicine brand. No gradients, no 3D, no clichés.
```

## Prompt negatywny (dla narzędzi, które go obsługują)

```
cartoon, 3D, glossy, neon, stock dental imagery, realistic face, misspelled text,
extra words, clutter, shadows, gradient, tooth icon, syringe, medical cross, stethoscope
```

## Jak pracować z wynikami

- Generatory często błędnie piszą tekst. Weź symbol z promptu 1 lub 2, a napis złóż w Canva/Figma czcionką Playfair Display i Inter (jak na stronie).
- Generuj 4–6 wariantów każdego promptu, wybierz jeden kierunek i dopracuj go w edytorze wektorowym.
- Potrzebne pliki: logo poziome, monogram „MK” (awatar na Instagram), wersja jasna i ciemna, SVG i PNG z przezroczystym tłem.
- Sprawdź monogram w małym kółku (zdjęcie profilowe) i w rozmiarze favicon.
- Kolory można zmienić w `web/src/styles/global.css`.
