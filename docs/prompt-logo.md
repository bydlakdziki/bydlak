# Prompt do logo – dr Marta Kryczka

## Prompt główny (do Midjourney, Ideogram, DALL·E, Canva AI itp.)

```
Minimalist elegant logo for "dr Marta Kryczka", a Polish dentist specialising in
aesthetic medicine and orthodontics. Wordmark-focused personal brand logo: the text
"dr Marta Kryczka" in a refined high-contrast serif typeface, with a small discreet
symbol beside or above it – a subtle abstract mark combining a soft smile curve with
balanced facial-profile lines, conveying harmony and proportion. Warm neutral palette:
deep taupe-brown (#5F452F), soft sand beige (#E9DDD0), off-white background (#FAF7F4).
Premium, calm, trustworthy, modern medical-aesthetic feel. Flat vector style, clean
thin lines, generous spacing, no gradients, no photorealism, no clichés such as
tooth icons, syringes, crosses or stethoscopes. Centered composition on a plain
background. Include a horizontal version and a compact monogram "MK".
```

## Wersja negatywna (czego unikać)

```
no cartoon, no 3D, no glossy effects, no neon colours, no stock dental imagery,
no faces with realistic detail, no misspelled text, no extra words
```

## Wskazówki

- Generatory obrazów często błędnie piszą tekst. Weź symbol z wygenerowanego obrazu, a napis złóż samodzielnie w Canva lub Figma czcionką np. Playfair Display (jak na stronie) i Inter.
- Poproś o 4–6 wariantów, wybierz jeden i dopracuj go w edytorze wektorowym.
- Potrzebne pliki: logo poziome, monogram „MK” (awatar na Instagram), wersja jasna i ciemna, format SVG i PNG z przezroczystym tłem.
- Sprawdź czytelność monogramu w małym kółku (zdjęcie profilowe).
- Kolory są zgodne z szatą strony w katalogu `web/`; można je zmienić w `web/src/styles/global.css`.
